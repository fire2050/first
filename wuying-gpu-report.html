01 执行摘要

核心结论：GPU 云桌面是 DaaS 的"第二增长曲线"

无影已从"办公替代"切入"算力消费"赛道。在具身智能、AI 科研、设计渲染三类高 GPU 负载场景驱动下，其商业模型正从低毛利的 seat 订阅，向高附加值的按需算力 + 模型差价（MaaS）迁移。

📌 我们判断的 5 件事

  • 1
    需求结构性上移。无影用户已超 200 万、日活桌面破 100 万，但真正的增量来自 GPU 场景——具身研发、数据采集、AI 科研对独占算力的需求正在爆发。[S1][S2]
  • 2
    市场被严重低估。Gartner 预测 DaaS 支出 2025 年 43 亿美元→2029 年 60 亿美元（CAGR 7.9%）；但 GPU 算力子集增速远超大盘，具身数据市场 CAGR 高达 36.8%。[S7][S9]
  • 3
    变现重心迁移。无影连续三年入选 Gartner 魔力象限并首进"挑战者"，商业化路径从"企业席位"升级为"订阅 + 企业席位 + API/Token 用量 + 模型差价"四轮驱动。[S7]
  • 4
    阿里云 AI 引擎加持。FY2026 云智能集团收入 1581 亿（+34%），AI 占比 30%，连续 11 季度三位数增长——为无影 GPU 场景提供底层算力与百炼 MaaS 弹药。[S3][S4]
  • 5
    客户即"卖水人"。银河通用、光轮智能、千寻智能等具身头部既是算力消耗方，又催生数据采集"卖水"生意（真机遥操 500–1000 元/小时），形成飞轮。[S9][S11]
机会窗口
未来 18 个月是 GPU 云桌面抢占具身/AI 科研客户的黄金期，先发者可锁定量产级数据闭环。
最大风险
GPU 供给与电价成本波动，以及华为云 Workspace 在政企信创市场的贴身竞争。
投资视角
关注"无影 + 百炼 MaaS + AgentBay"组合带来的 ARPU 提升，而非单纯 seat 数量。
行动建议
按场景打包"算力+数据+模型"套餐，把 GPU 桌面从成本中心卖成生产力平台。
02 核心读数

四类 GPU 高负载场景，构成需求基本盘

基于无影系列产品矩阵与场景化方案梳理，以下场景对独占 GPU、低延迟与弹性扩容最为敏感，是 GPU 云桌面付费意愿最强的客群。

🤖

具身智能研发

机器人/自动驾驶团队在云端运行仿真合成、遥操采集与模型训练。无影提供独占 GPU 池与远程图形工作站，避免本地机房建设。

客户：银河通用 / 光轮智能 / 千寻智能
🗄️

数据采集与合成

"卖水"模式：真机遥操 500–1000 元/小时，仿真合成按量计费。数据服务公司、舆情/竞品分析商是核心买家。[S9]

客户：市场研究 / 大数据服务公司
🎨

设计渲染 / 图形

RTX 5880 图形工作站增强型 1115 元/月；智己汽车设计团队以 457 元/周租用 GPU 桌面跑渲染，成本仅为自购 50%。[S5][S8]

客户：车企设计 / 影视动画
🔬

AI 科研 / 大模型

Qwen 镜像社区 + 7×24 常驻 Agent；AI 云超算顶配 4×RTX 5880、2 元/小时起，可跑 671B DeepSeek。[S6][S10]

客户：高校 / 科研院所
📞

智能呼叫中心

ASR/TTS 小模型可 RTX 5880 私有化，4→32 卡按并发扩容；独占算力池相比公共云 API 限流，保障低延迟。[S8]

客户：客服 BPO / 金融电销
🛡️

安全办公 / 信创

数据不落地 + 内网隔离，满足金融、政务合规。企业版时长包较电脑租赁成本仅 70%、自购 50%。[S8]

客户：金融 / 政务 / 多分支

06 单位经济与挑战

单卡 GPU 桌面的账，怎么算才赚钱

以下为单位经济测算（标注"估算"），用于说明 GPU 云桌面的盈利敏感点；真实成本受电价、GPU 利用率与折旧周期影响。

💰

收入侧

RTX 5880 增强型企业版 1115 元/月/席；若按 2 元/小时满负荷出租，单卡月收入可达 ~1440 元（估算）。叠加 MaaS 推理差价后 ARPU 进一步抬升。

估算 · 非公开披露
🔌

成本侧

单卡硬件折旧（按 3 年）+ 电费 + 带宽 + 运维，约占收入 45–60%（估算）。利用率是生命线：从 40% 提升到 70%，单位毛利可改善 15–20pct。

估算 · 敏感性高
📈

毛利与杠杆

GPU 桌面毛利估算 40–55%，远高于纯办公 seat；MaaS 模型差价层毛利可达 60%+（估算）。规模越大、利用率越高，单位成本越低。

估算 · 待财报验证
⚠️

核心挑战

• GPU 供给与电价：算力扩缩容受制于显卡采购与能耗成本波动。
• 利用率管理：独占算力池闲置即亏损，需调度算法提效。
• 信创替代压力：华为云 Workspace 在政企贴身竞争。
• 客户留存：中小 seat 用户黏性弱，需向"算力+模型"升舱。
• 合规边界：数据采集涉及隐私与跨境，需安全围栏（AgentBay）。

🛡️

护城河要素

• 算力池规模：背靠阿里云 FY2026 收入 1581 亿的资本开支。
• 模型闭环：百炼 MaaS + Qwen 生态形成"算力→模型"差价。
• Agent 原生：AgentBay 自进化引擎、记忆管理、安全围栏。
• 场景套餐：具身/数采/科研打包，提升切换成本。
• 客户飞轮：阿里战略投资宇树、自变量，绑定头部需求。

  • 模型差价（MaaS）打开高毛利第二曲线

🌩️ 威胁 Threats

  • 华为云在信创/政企的渠道与生态挤压
  • GPU 采购与电价成本上行压缩毛利

  • 数据合规与跨境监管收紧
08 趋势展望

未来 36 个月的三波浪潮

GPU 云桌面的需求曲线将由"具身数据爆发 → Agent 原生普及 → 模型差价规模化"逐级递进。

2026 H2

具身数据基础设施年

银河通用、光轮、千寻等头部进入量产数据闭环，真机遥操 + 仿真合成拉动独占 GPU 池需求；无影"算力+数据"套餐成型。

2027

Agent 原生云桌面普及

AgentBay 自进化引擎成熟，7×24 常驻 Agent 成为标配，桌面从"被人用"转为"被 Agent 用"，算力消耗结构性抬升。

2028+

模型差价成为主收入

百炼 MaaS 与无影桌面深度耦合，Token/推理差价占比超越 seat 订阅，ARPU 与毛利双升，打开估值想象空间。

② 客户分析：卡位、契合度与布防

竞争格局卡位：无影 vs 华为 vs 腾讯

• 无影：GPU 云桌面 + 弹性算力池 + 数据安全，绑定浅、易替换但难做深。
• 华为 CloudRobo：具身全栈平台（数据/模型/部署），联合研发+销售，绑定深。
• 腾讯 Tairos/EaaS：AI 数字基座 + 服务化交付（按机器人订阅），数据湖+训练底座。
结论：无影应打"最强 GPU 桌面 + 数据不落地 + 多厂商中立"差异化，尤其对"不想被单一云绑定"的客户（如光轮牵手西门子）是卖点。[S18][S20][S22]
